# Rakii Portfolio

This is my personal **portfolio website** built using **React** and **Vite**. It showcases my skills, projects, and experience as a developer. The portfolio is designed to provide potential employers, clients, and collaborators with an overview of my work and expertise.

## Project Description

The **rakii-portfolio** is a modern, interactive portfolio website created with the latest web technologies. The site is responsive and includes animations, charts, and interactive elements to provide a visually appealing experience.

## Features

- Interactive components with **React**.
- Animated effects with **React Parallax** and **Typewriter Effect**.
- Data visualization with **Chart.js** and **React Chart.js**.
- Responsive design using **Tailwind CSS**.
- Smooth scrolling using **React Scroll**.
- Particles background effects with **tsparticles** and **React TSParticles**.

## Tech Stack

- **React** (v18.3.1)
- **Vite** (v5.4.11) - Fast build tool and development server
- **Tailwind CSS** - Utility-first CSS framework for responsive design
- **Chart.js** - JavaScript library for data visualization
- **React Chart.js 2** - React wrapper for Chart.js
- **React Parallax Tilt** - For tilt animations in the UI
- **React Scroll** - For smooth scrolling navigation
- **Typewriter Effect** - For animated text typing
- **tsparticles** - For particles background effects
- **ESLint** - For linting and ensuring code quality
